# CI uses Go 1.26.11

The workflow installs Go 1.26.11. A scan on an older patch reports called standard-library vulnerabilities that this version fixes.

The `go` line, dependency bumps, and whether `govulncheck` fails the workflow are decided in [ADR 0008](0008-govulncheck-blocks-on-fixed-dependencies.md).

## History

This ADR first kept each `go.mod` on `go 1.25.4` and ran `govulncheck` with `continue-on-error` without upgrading `jackc/pgx`, `golang.org/x/text`, `golang.org/x/net`, `google.golang.org/grpc`, or `osrg/gobgp`. Installing Go 1.25.4 was rejected because that patch was off the current download list. Failing the workflow on `govulncheck` was rejected then because those findings were a separate dependency upgrade. [ADR 0008](0008-govulncheck-blocks-on-fixed-dependencies.md) took that upgrade and made the job blocking, except for the unfixed `bgp` finding.
